무료 카톡 테마

그림을 모두 새로 그려 만든 갤럭시·아이폰용 카톡 테마예요. 테마마다 내려받기 버튼과 파일 정보를 따로 적었어요. 모두 무료예요.

카카오와 관계없는 개인 제작물이며, 카카오톡 업데이트로 일부가 달라질 수 있습니다.

갤럭시(안드로이드)는 앱 파일(APK), 아이폰은 테마 파일(.ktheme)로 따로 받아요.

  • 수채화 카톡 테마 무료: 은행잎 골목, 늦가을 창가 불빛이 번지는 카톡 (갤럭시·아이폰)
  • 고양이 카톡 테마 무료: 구름 고양이 잠옷, 잠들기 전 카톡이 포근해져요 (갤럭시·아이폰)
  • 딸기 카톡 테마 무료: 딸기 토끼 피크닉, 카톡 열면 소풍 가는 기분 (갤럭시·아이폰)
  • 수달 카톡 테마 무료: 수건 수달, 카톡 열 때마다 온천에 온 기분 (갤럭시·아이폰)
  • 펭귄 카톡 테마 무료: 목도리 펭귄(갤럭시·아이폰)
  • 햄스터 카톡 테마 무료: 햄스터 빵집(갤럭시·아이폰)
  • 수채화 카톡 테마 무료: 달빛 호수, 밤에 카톡 열어도 눈이 편한 이유 (갤럭시·아이폰)
  • 수채화 카톡 테마 무료: 새벽 안개 정원, 카톡 켤 때마다 아침 산책하는 기분 (갤럭시·아이폰)
  • 가을 카톡 테마 무료: 도토리 숲의 가을(갤럭시·아이폰)
  • 큰 파도와 등대
  • 소용돌이 별밤
  • 겨울밤 남색

수채화 카톡 테마 무료: 은행잎 골목, 늦가을 창가 불빛이 번지는 카톡 (갤럭시·아이폰)

종이 질감이 보이는 수채화로 그린 늦가을 테마예요. 노란 은행잎이 떨어진 오래된 골목에 창가 불빛이 따뜻하게 번지고, 캐릭터 없이 풍경과 분위기로만 꾸몄어요. 잠금 화면은 키패드 아래까지 배경 그림이 이어지고, 말풍선, 탭 아이콘, 프로필, 시작 화면까지 수채화 질감으로 맞췄어요. 큰 그림은 Codex로 그렸어요.

테마 그림과 색으로 그린 미리보기예요(실제 화면 캡처가 아니에요).
